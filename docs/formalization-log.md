# Blueprint: formal proof of (H*) for spinless fermions on any connected graph (2026-11-06)

> Note (2026-11-06): the library was renamed from `LatticeDFT` to `DFT`; lattice files now live in
> `DFT/Lattice/` and the namespace is `DFT`. Older entries below use the old names.

Goal (Lean): for G connected (V = Fin M), 1 ≤ N ≤ M−1, uniform hopping t ≠ 0, any configuration-diagonal
interaction Vint, and every configuration c: `krylovPoly (Tf + Vint) occ c Fin.val ≠ 0`.
Combined with J4/J5 this gives: HK holds for Lebesgue-a.e. potential on every such lattice.

Mathlib gaps that force the route: no eigenvector perturbation theory, no Henselian/complete instance for
power series, immature exterior powers. Route chosen to need only: spectral theorem for symmetric matrices,
Gershgorin, Neumann series, Cauchy–Binet, polynomial degree arguments.

B0  Definitions. C = {s : Finset (Fin M) // s.card = N}; fermionic hopping matrix Tf (sign = (−1)^{#occupied
    sites strictly between}); occ; H(v) = Tf + Vint + diag(occ·v).                                   [small]
B1  Second quantisation. For a single-particle symmetric h, Γ(h) on C; Tf + diag(occ·v) = Γ(−tA + diag v).
    Slater lemma: h φ_j = ε_j φ_j ⇒ Ψ_S(c) := det[φ_{s_i}(c_j)] satisfies Γ(h)Ψ_S = (Σ_{j∈S} ε_j) Ψ_S.
    Orthonormality of {Ψ_S} via Cauchy–Binet.                                          [heavy: fermion signs]
B2  Single-particle asymptotics (N = 1), v = λu, u with distinct entries: every eigenpair (E, φ) of
    h(λu) for λ ≥ λ0 has E = λu_a + O(1) for a unique a (Gershgorin), and
    φ(b)/φ(a) = λ^{−d(a,b)} (a_ab(u) + O(1/λ)) (Feshbach + Neumann series), a_ab = single-particle path sum. [heavy]
B3  Determinant asymptotics: for the Slater state of S = x, the c-amplitude is λ^{−m}(D(u) + O(1/λ)),
    D(u) = Σ_{π∈Opt} sign π Π a_{x_i c_π(i)}(u).                                                  [medium]
B4  Resonance lemma: D ≢ 0 (choose π0 fixing x∩c; on V = {u_{x_i} = u_{c_π0(i)}} the π0 term has the
    strictly highest pole order; S_i ≢ 0 by pushing a class to +∞). Formalise with polynomials: clear
    denominators, compare ε-adic orders.                                                          [heavy]
B5  Free fermions: P_free(λu) = det Φ · Π_x Ψ_x(c) · Vand(E) ≍ λ^E with nonzero constant
    (E = L(L−1)/2 − Σ_x dist(x,c)) ⇒ the degree-E homogeneous part of krylovPoly is nonzero.      [medium]
B6  Interaction drops out: every monomial of krylovPoly of total v-degree E is independent of Vint (each Vint
    factor replaces a v-factor in a walk of fixed length), and E is the maximal degree.
    ⇒ krylovPoly(Tf + Vint) ≠ 0 for every Vint.                                                   [medium]
B7  Assemble with J4/J5: `generic_hk_ae_all_lattices`.                                            [small]

Estimate: several thousand lines of Lean over multiple sessions. Order of attack: B0 → B1 (riskiest
infrastructure) → B6 (pure algebra) → B2/B3 → B4 → B5 → B7. Each milestone is useful on its own
(e.g. B1 = formal Slater-determinant theorem for lattice fermions).

## Kohn–Sham and extensions (2026-11-06, after the restructuring; module names as in the current tree)
- KS1 `KohnSham/Aufbau`: aufbau via Cauchy–Binet; `aufbau_lowest` (minimisers = sets of lowest orbitals,
  exchange argument).
- KS2 `KohnSham/Uniqueness`: generic uniqueness of the KS potential (generic HK with Vint = 0).
- KS3 `KohnSham/Duality`: Lieb functional, duality, convexity.
- KS4 `KohnSham/Maximizer`, `Representability`, `Existence`: ensemble v-representability of strictly positive
  mixtures (maximiser via coercivity, limit argument, Hahn–Banach separation).
- KS4b `KohnSham/Hypersimplex`: vertex description of the hypersimplex (induction on fractional sites);
  `ks_potential_exists_interior`: every ρ with 0 < ρ_i < 1, Σρ = N has a KS potential.
- KS5 `KohnSham/Iteration`, `Convex/MoreauYosida`, `KohnSham/RegularizedKS`: convergence of MYKSODA
  (Penz–Laestadius–Tellgren–Ruggenthaler PRL 123, 037401 (2019)). NOTE: the original letter's convergence claim
  is wrong (erratum with P. E. Lammert): ‖x_{i+1} − x_i‖ → 0 does not give a Cauchy sequence. We formalise the
  corrected statement: decreasing energies, ∇F_ε(x_i) + v → 0, accumulation points exist and are regularised
  ground-state quasi-densities z, energies converge to the minimum, z + εv is a true (Lieb) ground-state
  density, and the KS potentials converge along the subsequence to v_KS with z + εv_KS the KS density.
  Abstract layer needs no derivatives: only the two inequalities of `IsMYSmooth`.
- Weighted hopping: the PathSum chain takes edge amplitudes `t a b`; only `Lval_ne_zero` uses the sign
  condition ∃ s, s·t_ab > 0 on edges. `generic_hk_lattice_fermions_w`; the uniform theorem is a corollary.
